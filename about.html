About ComputePedia

ComputePedia is a simple educational website created to explore processors, processor architectures, and the technologies behind modern computing.

The processors on this website are organized mainly by architecture. The three main categories are x86 / x86-64, ARM, and RISC-V.

Each architecture page contains processor cards showing the processor name, manufacturer, process node, and cores / threads. The processor images can also be opened separately for a closer look.

ComputePedia is a front-end project built using simple HTML and CSS without other frameworks.
